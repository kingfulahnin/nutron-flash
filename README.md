## 🚀 HOW TO DEPLOY

1. Clone the repo  
2. Run: `npm install`  
3. Dev mode: `npm run dev` (or `next dev` if using Next.js)  
4. Deploy to Netlify, Vercel, or custom host  
5. (Optional) Load API via Postman collection in `/postman/`
